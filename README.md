# Label Sticker — прототип сайта

Прототип [mulinmedia.ru](https://mulinmedia.ru/).

Адаптивная HTML-версия: главная, термоэтикетки, термотрансферные этикетки, риббоны и этикетки А4. Откройте `index.html` в браузере; сохраняйте все HTML-файлы в одной папке.

Дизайн, стили, иллюстрации и логика встроены в страницы. Сборка и зависимости не требуются.

Форма подготавливает текст запроса для копирования или скачивания. Приём заявок и счётчик Метрики ещё не подключены. Подробности запуска — в `START-HERE.txt`.

Прототип не заменяет действующий сайт label-sticker.ru. Перед публикацией на другом домене обновите canonical, Open Graph, микроразметку и sitemap.
